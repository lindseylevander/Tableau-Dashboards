# Olist eCommerce Performance Dashboard

Project Overview

This project analyzes customer behavior, revenue performance, product sales, and delivery metrics using the Brazilian Olist e-commerce dataset.

The dashboard was built in Tableau Public using data prepared through SQL joins across multiple relational tables.

Dashboard Features
- Revenue KPI tracking
- Order volume analysis
- Customer analysis
- Product category performance
- Delivery performance monitoring
- Geographic order distribution
- Interactive filters

Business Questions Answered
- Revenue Performance
  - How has revenue changed over time?
  - Are there seasonal trends?
- Customer Insights
  - Which states generate the most orders?
  - How many unique customers place orders?
- Product Analysis
  - Which product categories generate the most revenue?
  - Which categories drive order volume?
- Operations
  - How long does delivery take on average?
  - Which regions experience longer delivery times?
