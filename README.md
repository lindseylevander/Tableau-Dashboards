# Tableau-Dashboards

This repository serves to store different Tableau projects and organize them in one place. Each branch will be its own project with its own README.

# Branch 1: Olist eCommerce
This project analyzes ecommerce data from the Olist eCommerce dataset found on Kaggle. SQL is used to identify consumer KPIs like monthly revenue trends and delivery time frames. Tableau is used to create a performance dashboard based off of these KPIs.
